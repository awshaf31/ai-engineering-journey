## Install pytest
- The virtual environment must be active:

```bash
source .venv/bin/activate
pip install pytest
pytest --version
```

## Run the tests
- Run this from the repository root (the `ai-engineering-journey` folder):

```bash
pytest lesson03 -v
```
- `-v` shows the name of each test.
